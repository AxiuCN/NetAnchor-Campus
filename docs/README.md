## 约定

- `docs/` 下的文档**入库**并与代码一同提交；`docs/private/` 放本机信息，**不入库**（已 gitignore）
- 入库文档只写占位（`<portal-host>` / `<安装目录>` / `<machine>`），不得出现真实地址、账号、机器名、本机绝对路径
- 行为变化时同批更新对应文档；文档落后于代码视为未交付
- 文档之间用相对链接互引；改了文件名要全仓搜旧名
